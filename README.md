# KeyCRM — push при новому ліді

## Головне

У KeyCRM **немає** окремого push «новий лід». OpenAPI **не вміє** слати push у мобільний додаток і **немає** API задач.

Офіційний спосіб отримати push у додатку keyCRM:

**Тригер:** новий лід (статус «Новий») → **Створити задачу** відповідальному → push приходить як сповіщення про задачу.

### Кроки в KeyCRM

1. **Налаштування → Додатково → Автоматизація → Додати тригер**
2. Подія: **Воронки → Зміна статусу → Новий**
3. Час: **Одразу**
4. Дія: **Створити задачу**
   - Назва: `Новий лід — потрібно звʼязатись`
   - Відповідальний: **Гасинець Аліса** (отримує push)
   - Постановщик: **Влад Спеціаліст** (інший користувач — інакше push про створення не прийде)
5. Профіль Аліси → **Сповіщення** → увімкнути **PUSH** для завдань
6. У телефоні дозволити сповіщення додатку **keyCRM**

### Ваш акаунт (перевірено API)

| Що | Значення |
|---|---|
| Воронка | Ліди `#1` |
| Статус нового ліда | Новий `#1` |
| Адмін (отримувач) | Гасинець Аліса `#3` |
| Постановщик задачі | Влад Спеціаліст `#4` |
